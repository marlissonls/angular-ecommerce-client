# Angular Ecommerce Client

Frontend do projeto Ecommerce desenvolvido com Angular e TypeScript.

## Tecnologias

- Angular
- TypeScript
- Angular Router
- Angular HttpClient
- Vitest

## Requisitos

- Node.js
- npm
- Angular CLI

## Instalação

```bash
npm install
```

## Executar em desenvolvimento

```bash
npm start
```

## Build de produção

```bash
npm run build
```

## Configuração

As configurações públicas do frontend devem ser definidas nos arquivos de ambiente do Angular.

Não armazenar senhas, tokens secretos ou chaves privadas no código ou nos arquivos de ambiente enviados ao navegador.

## Observações

Este projeto corresponde à aplicação frontend Angular do Ecommerce.
